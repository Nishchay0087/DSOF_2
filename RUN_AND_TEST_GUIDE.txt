15. UNDERSTAND SCORES AND LABELS
-------------------------------
DSI = 0.35 E + 0.30 I + 0.20 D + 0.15 P, on a 0-100 scale.
E: session duration and number of actions.
I: diversity and depth of recorded actions.
D: observed connection-share proxy within configured capture/protected-port scope.
P: prior same-source/same-origin sessions within 24 hours.

D is not proof that an attack was prevented. An unavailable total score means
required telemetry is missing; it is not silently replaced by zero.
Repeated localhost tests can have high P because every test uses the same IP.

The behavior tier uses ten minutes of source activity:
Beginner: fewer than five destination ports and ten flows.
Intermediate: at least five destination ports OR ten flows.
Advanced: at least twenty destination ports AND three destinations.
Repeated test scripts use new temporary ports and can raise this tier. It does
not measure a person's expertise. It is independent of ML classification.

The supplied flow model's 97.13% result is a reconstructed offline dataset result.
The HTTP model is trained on project-authored synthetic strings. Its held-out
synthetic results are documented in docs/HTTP_CONTENT_ML.md. Neither figure is
proof of live real-world accuracy. Prediction probabilities are uncalibrated.

QUICK TROUBLESHOOTING
---------------------
Buttons disabled: System -> Operator access -> unlock with data/control.token.
Waiting for capture helper: start/restart Terminal B's capture command.
503 from a test: check readiness; the backend can run while capture is unavailable.
Connection refused on 8081/2222/3307: start that honeypot and wait for Listening.
No new Traffic row: wait for the idle timeout and check the Origin filter.
No HTTP ML result: old evidence, non-HTTP flow, or unsupported/incomplete parsing.
Only flow ML says BENIGN: inspect the separate HTTP ML prediction.
No session after an alert: connect to the decoy; there is no automatic redirection.
No learning rankings: controlled tests and unattributed sessions do not train it.
Another instance/port in use: use the existing backend; do not launch a duplicate.
